# Abdelilah Gaming

متجر PHP بسيط يعمل على XAMPP بدون MySQL وبدون APIs خارجية.

## التشغيل
1. ضع المجلد داخل `htdocs`.
2. شغل Apache من XAMPP.
3. افتح `http://localhost/Abdelilah-Gaming/install.php`.
4. أنشئ حساب المدير.
5. ادخل إلى `admin_login.php`.
6. أضف المنتجات واضبط التوصيل والخدمات.

## هيكل المشروع
جميع الملفات موجودة مباشرة داخل المجلد الرئيسي بدون مجلدات فرعية (لا `admin/`، ولا `includes/`، ولا `assets/`، ولا `data/`، ولا `uploads/`). صفحات لوحة المدير تحمل بادئة `admin_` (مثل `admin_products.php`، `admin_users.php`) باستثناء لوحة التحكم الرئيسية `admin.php`.

## GitHub
هذا المشروع مناسب لرفعه إلى GitHub، لكن لا ترفع بيانات العملاء أو كلمات مرور حقيقية إلى مستودع عام.

## التخزين
البيانات تحفظ في ملفات JSON داخل نفس المجلد الرئيسي (مثل `products.json`، `users.json`)، وهي محمية من الوصول المباشر عبر المتصفح بواسطة ملف `.htaccess`. صور المنتجات والخدمات تُوضع أيضاً داخل نفس المجلد الرئيسي ويُكتب اسم الملف فقط (مثل `item.jpg`) في حقل الصورة.
